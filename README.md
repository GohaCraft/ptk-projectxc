# 🏛️ ЗГУ • 3D Цифровой двойник Политехнического колледжа

Интерактивный **3D-цифровой двойник** здания Политехнического колледжа (ЗГУ, Норильск): три корпуса (Б, Б1, Б2), поэтажные срезы, реальная планировка по чертежам БТИ, динамическое небо и погода Норильска. Работает как **веб-приложение** и как автономное **Windows-приложение (.exe)** с авто-обновлением.

Построен на **Next.js 14 + React 18 + Three.js / React Three Fiber**, упакован в **Electron**. Отдельное внимание — оптимизации под слабый киоск (Core i3 / 4 ГБ).

---

## ✨ Возможности

- **Точная 3D-модель здания** — корпуса Б / Б1 / Б2, цоколь, башни, парадная группа, пандус, окружение Норильска.
- **Поэтажные срезы** — этажи 1–4, подвал и крыша; плавные переходы между уровнями.
- **Реальная планировка** — внутренние стены трассированы прямо с чертежей БТИ (масштаб 1:200), наложение PDF/SVG-чертежей на пол.
- **Интерактивные зоны** — кликабельные помещения с концепциями интерьеров.
- **Три режима камеры** — 🛰️ 3D-орбита, 🗺️ 2D-сверху, 🚁 Облёт (с экранным джойстиком для киоска без клавиатуры).
- **Твёрдые стены (коллизии)** — камера не проходит сквозь объекты, может скользить вдоль стен.
- **Динамическое солнце** — реальные координаты Норильска через `suncalc`, полярный день/ночь, белые ночи.
- **Реалистичное небо и облака** — лёгкий шейдерный слой облаков (FBM), покрытие по реальной облачности, дрейф по ветру.
- **Погода Норильска** — дождь, снег, гроза с молниями, **туман**; осадки наклоняются по реальному ветру.
- **Мульти-источниковый мониторинг погоды** — Open-Meteo, MET Norway, wttr.in с перекрёстной проверкой (медиана); работает и офлайн (сезонный расчёт).
- **Система версий** — окно «Что нового» при первом запуске новой версии + полная история (кнопка ℹ️).
- **Авто-обновление** — `.exe` сам обновляется из GitHub Releases (`electron-updater`).
- **Настройки для преподавателя** — файл `app/config/appSettings.ts`: включение/отключение анимаций, теней, погоды, зон, чертежей, блокировки модели и т.д.
- **Система номеров ошибок** — при сбоях внизу появляется плашка с номером и местом ошибки.
- **Авто-оптимизация** — адаптивное разрешение и уровни качества (low/medium/high) под мощность ПК.

## 🚀 Быстрый старт (веб)

Требования: **Node.js 18.17+** (рекомендуется **20.x LTS**).

```bash
npm install      # .npmrc уже настроен (legacy-peer-deps) — конфликтов 3D-библиотек не будет
npm run dev      # режим разработки
```

Откройте 👉 **http://localhost:3000**

Прод-сборка веб-версии:

```bash
npm run build
npm run start
```

## 🖥️ Сборка Windows-приложения (.exe)

```bash
npm run desktop:export   # статический экспорт в out/ (временно отключает app/api для экспорта)
npm run desktop:start    # тест в окне Electron
npm run desktop:dist     # сборка установщика .exe
```

Готовый установщик появится в `desktop/output/` —
**`ZGU-3D-Model-Setup-<версия>.exe`** (NSIS, с выбором папки и ярлыками).

### Публикация релиза с авто-обновлением

```powershell
$env:GH_TOKEN="<github_token_с_правом_repo>"
npm run desktop:publish   # сборка + загрузка в GitHub Releases
```

electron-builder создаст релиз с тегом `v<версия>` и зальёт `.exe`, `.blockmap` и `latest.yml`.
Установленные копии обновятся автоматически. Подробности — в [`RELEASE.md`](RELEASE.md) и [`DESKTOP_BUILD.md`](DESKTOP_BUILD.md).

## 📁 Структура проекта

```
app/
├─ api/weather/route.ts        # мульти-источниковый агрегатор погоды (только веб)
├─ config/appSettings.ts       # настройки для преподавателя (вкл/выкл функций)
├─ components/
│  ├─ graphics/                # сцена, корпуса, солнце, небо, погода, материалы
│  │  ├─ Scene3D.tsx           # Canvas, свет, тени, авто-оптимизация
│  │  ├─ DynamicSun.tsx        # солнце, небо, облака, разбор погоды
│  │  └─ Weather.tsx           # дождь/снег/гроза/туман
│  ├─ controls/CameraManager.tsx  # режимы камеры, коллизии, джойстик
│  ├─ ui/                      # стартовое меню, загрузчик, «Что нового», ошибки
│  └─ data/                    # changelog, состояние погоды, фолбэк, перф-тиры
electron-main.js               # точка входа Electron, локальный сервер, авто-апдейт
scripts/desktop-export.mjs     # подготовка статического экспорта для .exe
```

## ⚙️ Настройки для преподавателя

В файле [`app/config/appSettings.ts`](app/config/appSettings.ts) — переключатели `true/false` с пояснениями на русском: цифры над блоками, анимации, погода по API, зоны, тени, время суток, блокировка модели, чертежи, редактор стен.
