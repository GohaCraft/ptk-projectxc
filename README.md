# 🎓 3D-Редактор Здания и Чертежей ЗГУ

Добро пожаловать в проект интерактивного 3D-редактора кампуса ЗГУ! Это полноценное full-stack приложение, построенное на современных веб-технологиях (**Next.js**, **React 18**, **Three.js** / **React Three Fiber**) с поддержкой компиляции в десктопное приложение (**Electron**).

Мы проделали огромную работу, чтобы проект запускался у вас локально в **VS Code** с первого клика, без ошибок и конфликтов версий.

---

## ⚡ Быстрый старт в VS Code

### Требования к вашей системе
* **Node.js**: Версия **18.17.0+** (Рекомендуется стабильная **20.x LTS** или **22.x LTS**).
  * *Пожалуйста, убедитесь, что вы обновили Node.js на компьютере! Более старые версии (например, v14 или v16) несовместимы с современным Next.js и вызовут ошибки сборки.*

---

### Шаг 1. Открытие проекта в VS Code
1. Распакуйте скачанный zip-архив с проектом в удобную вам папку.
2. Запустите **VS Code**.
3. Выберите `Файл` -> `Открыть папку...` (`File` -> `Open Folder...`) и выберите папку с проектом.

---

### Шаг 2. Автоматическая и безопасная установка зависимостей
Откройте встроенный терминал в VS Code (нажмите ``Ctrl + ` `` или выберите `Терминал` -> `Создать терминал`) и введите команду:

```bash
npm install
```

> **🛡️ Что мы настроили для защиты установки:**
> * Мы создали файл `.npmrc` с параметром `legacy-peer-deps=true`. Теперь вам **не нужно** вводить флаги вручную! Обычная команда `npm install` автоматически обойдет конфликты зависимостей 3D-библиотек (React Three Fiber, Drei) и установит все модули корректно.
> * Файлы `.nvmrc` и `.node-version` укажут вашему менеджеру версий на работу с современной **Node.js v20**.

---

### Шаг 3. Запуск веб-версии
Для запуска режима разработки введите:

```bash
npm run dev
```

Приложение запустится локально. Перейдите в браузере по адресу:
👉 [**http://localhost:3000**](http://localhost:3000)

---

### Шаг 4. Сборка десктопного `.exe` приложения
Если вы хотите собрать автономный `.exe` файл для показа комиссии, следуйте шагам:

1. **Сделайте статический экспорт приложения:**
   ```bash
   npm run desktop:export
   ```
   Эта команда соберет оптимизированный HTML/CSS код в папку `out/`.

2. **Запустите тестирование десктопного режима:**
   ```bash
   npm run desktop:start
   ```
   Откроется нативное окно программы с 3D-моделью.

3. **Скомпилируйте готовый `.exe` файл:**
   ```bash
   npm run desktop:dist
   ```
   После завершения вы найдете готовый файл `ZGU-Model-3D Portable.exe` в папке `dist-desktop/`. Перенесите его на флешку и запускайте на любом ПК с Windows без установки и интернета!
