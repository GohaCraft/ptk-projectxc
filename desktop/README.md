# Десктоп-сборка: модель ЗГУ в виде .exe (Windows)

Эта папка — **основа для упаковки веб-модели в Windows-приложение (.exe)**.
Здесь лежат скрипты и инструкция, которые из текущего веб-проекта собирают
**установщик** (NSIS `Setup.exe`). Конечный пользователь запускает установщик →
получает на рабочем столе ярлык «ЗГУ 3D Модель» → приложение работает офлайн,
без интернета и без браузера.

> Статус: **заготовка**. Мы вернёмся к ней в конце, когда добьём веб-версию.
> Сейчас всё уже настроено и рабочее — достаточно запустить один скрипт.

---

## Как это устроено

1. `npm run desktop:export` — Next.js собирает **статический** экспорт сайта в
   папку `out/` (флаг `EXPORT_MODE=true`, см. `next.config.mjs`).
2. `npm run desktop:dist` — `electron-builder` берёт `electron-main.js` + `out/`
   + `public/` и пакует их в установщик.
3. `electron-main.js` поднимает встроенный локальный сервер (offline) и
   открывает модель в окне Electron — поэтому 3D-текстуры, `walls.json`,
   `plan_manifest.json` и картинки плана грузятся локально, без CORS и сети.
4. Готовый установщик появляется в **`desktop/output/`**
   (имя вида `ZGU-3D-Model-Setup-<версия>.exe`).

---

## Быстрая сборка (Windows)

Нужен установленный **Node.js 18+** (https://nodejs.org).

Дважды кликни по **`build-windows.bat`** (или запусти из терминала):

```bat
desktop\build-windows.bat
```

Скрипт сам: поставит зависимости → соберёт статический экспорт → соберёт
установщик. По окончании в `desktop/output/` будет:

- `ZGU-3D-Model-Setup-<версия>.exe` — **установщик** (его и кладём в архив);
- `win-unpacked/` — распакованное приложение (можно запускать без установки).

PowerShell-вариант: `desktop\build-windows.ps1`.

---

## Что отдавать пользователю

Заархивируй (`.zip`) **только установщик** из `desktop/output/`:

```
ЗГУ-3D-Модель.zip
└── ZGU-3D-Model-Setup-<версия>.exe
```

Пользователь распаковал → запустил `Setup.exe` → выбрал папку → установил →
ярлык на рабочем столе. Готово, модель как полноценный .exe.

---

## Иконка (опционально)

Положи свою иконку в `desktop/assets/icon.ico` и поменяй путь `win.icon`
в `package.json` (`"build" → "win" → "icon"`). Сейчас используется
`public/favicon.ico`.
