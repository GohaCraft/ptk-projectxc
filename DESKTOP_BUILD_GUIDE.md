# ИНСТРУКЦИЯ: Сборка 3D-редактора в автономный `.exe` файл для Windows

Мы подготовили и внедрили в ваш проект конфигурацию **Electron + electron-builder**. Это позволит вам скомпилировать веб-приложение в полноценную десктопную программу для Windows (готовый `.exe`), которую можно запускать без интернета, переносить на флешке и показывать комиссии.

---

### Как это устроено "под капотом":
1. **Безопасный статический экспорт (`output: 'export'`)**: Приложение преобразуется в чистый HTML/CSS/React-код, не требуя запущенного сервера Node.js.
2. **Внедрённый локальный HTTP-сервер**: Внутрь `.exe` встроен микро-сервер (в файле `electron-main.js`), который автоматически запускается на свободном порту Windows. Это **критически важно** для 3D (Three.js / React Three Fiber) и загрузки планировок БТИ: так мы обходим ограничения CORS и политики безопасности `file://` протокола. Текстуры, тени и файлы будут загружаться мгновенно и без ошибок.
3. **Презентационные горячие клавиши**:
   * `F11` — Переключить во весь экран (удобно для показа комиссии).
   * `F12` — Открыть консоль разработчика (DevTools).
   * `F5` или `Ctrl + R` — Обновить интерфейс приложения.

---

## 🚀 Пошаговая сборка десктопной версии (на вашем компьютере)

Запустите **VS Code** и откройте терминал в папке вашего проекта (`Z:\Desktop\generated (2)`), после чего выполните следующие шаги:

### Шаг 1. Установка десктопных зависимостей
Чтобы установить Electron и инструменты сборки без конфликтов версий (peer dependencies), используйте флаг `--legacy-peer-deps`:

```bash
npm install electron electron-builder cross-env --save-dev --legacy-peer-deps
```

*Если вы хотите просто обновить все модули в проекте, запустите:*
```bash
npm install --legacy-peer-deps
```

---

### Шаг 2. Сборка статических файлов приложения
Скомпилируйте React-код в статическую сборку для десктопа:

```bash
npm run desktop:export
```
Эта команда создаст папку `out` в корне вашего проекта, содержащую оптимизированные статические страницы.

---

### Шаг 3. (Опционально) Тестирование десктопного режима
Перед тем, как собирать запечатанный файл, вы можете запустить приложение в окне Electron для проверки:

```bash
npm run desktop:start
```

---

### Шаг 4. Компиляция в готовый `.exe` файл
Запустите команду сборщика для Windows:

```bash
npm run desktop:dist
```

Сборщик скачает необходимые бинарные файлы Electron и упакует ваше приложение. Сборка займёт около 1-2 минут.

---

## 🎯 Где забрать готовые файлы?

После успешной сборки в корне вашего проекта появится новая папка **`dist-desktop/`**. Внутри неё находятся:

1. **`ZGU-Model-3D [Версия] Portable.exe`** — **Портативная версия!**
   * Это один единый `.exe` файл.
   * Его можно скинуть на флешку, перенести на любой другой компьютер c Windows и запустить двойным кликом. Установка не требуется! Идеально для демонстрации комиссии.
2. **`ZGU-Model-3D Setup [Версия].exe`** — Программа установки.
   * Обычный инсталлятор Windows, который устанавливает приложение на компьютер и добавляет ярлык на рабочий стол.

---

### 💡 Советы для защиты работы перед комиссией:
* **Загрузка планировок**: Все загруженные через интерфейс подложки БТИ и стены теперь отлично сохраняются прямо в браузерном хранилище вашего локального приложения, так как Electron изолирует кэш для программы индивидуально.
* **Полноэкранный режим**: При запуске на защите нажмите клавишу **`F11`** — рамки Windows и строка заголовка исчезнут, и приложение будет выглядеть как профессиональный нативный софт.
