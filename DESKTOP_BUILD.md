# Сборка десктоп-приложения (.exe) и установщика — ЗГУ 3D Модель

Приложение оборачивается в **Electron** и собирается в установщик **NSIS** (`Setup.exe`)
и в переносимую версию (`portable.exe`). Конфигурация уже в `package.json` (поле `build`),
точка входа — `electron-main.js`, статика берётся из `out/` (Next.js export).

## Что нужно один раз
- **Windows 10/11 x64** (на Windows wine НЕ нужен — всё собирается из коробки).
- **Node.js ≥ 18** (а лучше 20+): https://nodejs.org
- Git (по желанию).

> На Linux/macOS собрать **Windows-установщик** напрямую нельзя без `wine`
> (этап NSIS/подписи требует wine). Поэтому установщик собираем на Windows.

## Шаги (PowerShell или cmd в папке проекта)

```bat
:: 1. установить зависимости
npm install

:: 2. собрать статику приложения (создаёт папку out/)
npm run desktop:export

:: 3. собрать установщик + portable .exe
npm run desktop:dist
```

Готовые файлы появятся в **`desktop/output/`**:
- `ZGU-3D-Model-Setup-<версия>.exe` — **установщик** (ярлык на рабочий стол и в меню «Пуск», выбор папки установки);
- `ZGU-3D-Model-<версия>.exe` (portable) — **запуск без установки**.

## Быстрая проверка без сборки установщика
```bat
npm run desktop:export
npm run desktop:start     :: откроет приложение в окне Electron
```

## Если хочется только папку с .exe (без инсталлятора)
```bat
npm run desktop:export
npm run desktop:pack      :: положит распакованное приложение в desktop/output/win-unpacked/
```
Внутри — `ZGU-Model-3D.exe`, рядом нужные DLL (запускать прямо оттуда).

## Иконка
Иконка приложения берётся из `public/favicon.ico`. Чтобы сменить — замени этот файл
(формат .ico, желательно с размерами 16–256 px).

## Почему «установщик не появился, просто открылась моделька»
В `desktop/output/` лежат **два** .exe:
- `ZGU-3D-Model-Setup-<версия>.exe` — это **установщик** с мастером (приветствие,
  лицензия, выбор папки, ярлыки). Запускать нужно **именно его**.
- `ZGU-3D-Model-<версия>.exe` (portable) — запускается **сразу**, без установки —
  поэтому «просто открывается моделька». Это не баг, это переносимая версия.

Если нужен мастер установки — запускай файл со словом **Setup** в имени.

## Дизайн установщика
Установщик — **современный one-click** (как у Discord / VS Code): одно компактное
окно с иконкой приложения и анимированной полосой прогресса. Без страниц мастера,
без серых системных кнопок и выбора папки — ставится автоматически в пользовательскую
папку и сразу запускается.

- Иконка окна установки — `public/favicon.ico` (хотите красивее — замените .ico).
- Лицензии и выбора каталога в one-click режиме нет (это осознанный выбор ради
  чистого современного вида).

> Примечание: кнопки/рамку обычного «мастера» Windows перекрасить нельзя — это
> системные элементы. Поэтому для красивого вида выбран one-click формат.

## Как проходит установка и удаление
Установщик (`...Setup-<версия>.exe`):
1. Двойной клик — открывается одно окно с иконкой и **полосой прогресса**.
2. Программа сама ставится в пользовательскую папку (без запроса прав администратора).
3. По завершении приложение **запускается автоматически**.

После установки создаются:
- **ярлык на рабочем столе** (`createDesktopShortcut: always`),
- ярлык в меню «Пуск» (папка «ЗГУ»),
- в папке установки — файл **`Uninstall ЗГУ 3D Модель.exe`**.

При запуске Uninstall всплывает окно **«Вы уверены, что хотите удалить?»**
(см. `build/installer.nsh`), и при подтверждении программа и её данные удаляются
(`deleteAppDataOnUninstall: true`). Удалить также можно через
«Параметры → Приложения» в Windows.

## Авто-обновление с GitHub
Приложение при запуске проверяет последний **Release** в репозитории
`GohaCraft/ptk-projectxc` и, если вышла новая версия, тихо скачивает её и предлагает
перезапуститься. Используется `electron-updater` (см. `electron-main.js`).

Чтобы выкатить обновление, на Windows:
```bat
:: токен с правом publish (repo). Получить: GitHub → Settings → Developer settings → Tokens
set GH_TOKEN=ghp_ВАШ_ТОКЕН

npm run desktop:export
npm run desktop:publish    :: соберёт и зальёт релиз + latest.yml в GitHub Releases
```
Версия берётся из `package.json` → поле `version` (сейчас **1.22.0**).
Перед публикацией подними `version` (и добавь запись в `app/components/data/changelog.ts`).

> Для авто-обновления релиз должен содержать `latest.yml` и `*-Setup-*.exe` —
> `electron-builder --publish always` создаёт их сам. Без публикации релизов
> авто-апдейтер просто молча ничего не делает (приложение работает как обычно).

## Система версий внутри приложения
- При **первом запуске новой версии** показывается окно «Что нового».
- Кнопка **(i)** в правом верхнем углу открывает **всю историю версий**.
- Список версий редактируется в `app/components/data/changelog.ts`
  (новые версии добавляются в начало массива, `APP_VERSION` = верхняя версия).

## Примечания
- Приложение работает **полностью офлайн** (Next.js export + локальный мини-сервер внутри Electron).
- Онлайн-функции (погода/прокси-картинки) в десктоп-версии отключены — это нормально.
- Папки `out/` и `desktop/output/` в репозиторий не коммитятся (см. `.gitignore`).
